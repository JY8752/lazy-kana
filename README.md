# 🌈 かなあそび

親子でキーボードに触って遊ぶ、ひらがなのターミナルおもちゃです。
Go / Bubble Tea / Lip Glossで作った、小さなプロトタイプです。

## 起動

Go 1.25以上と、日本語・絵文字が表示できるターミナルが必要です。
macOSのTerminalやiTerm2などで、次のコマンドを実行してください。
初回のみ、Goの依存ライブラリのダウンロードにネット接続が必要です。

```bash
go run .
```

`NO_COLOR=1` が設定されている場合は色が無効になります。
色を付けて遊ぶには `NO_COLOR=0 go run .` で起動してください。

80列 × 24行以上をおすすめします。ウィンドウに合わせて中央寄せします。
40列 × 18行未満では、サイズを広げる案内を表示します。

## 操作

| キー | 操作 |
| --- | --- |
| ↑ / ↓ | メニューの選択 |
| Enter | 選んだ遊びを開始 / 名前入力の決定 |
| 1〜5 | メニューから各遊びを直接開始 |
| d | メニューで文字表示を「ふつう / ドット」に切り替える |
| Space | 次の文字 / 答え / 次の問題 / 次の列車 |
| Esc | どの画面からでもメニューへ戻る |
| q | メニューでのみ終了 |
| Ctrl+C | どこからでも終了 |
| Backspace / Delete | 名前入力の最後の1文字を削除 |

## 5つの遊び

1. **あいうえお** — 「あ」から「ん」まで順番に表示します。最後は「あ」に戻ります。
2. **おなまえ** — 親が名前を入力し、Enterで開始。Spaceで1文字ずつ進み、最後の次に名前全体をお祝い表示します。さらにSpaceでもう一周できます。入力し直すときはEscで戻り、「おなまえ」を選び直してください。
3. **むし食い** — ランダムな行から1文字が隠れます。Spaceで答え、もう一度Spaceで次の問題です。
4. **まちがい探し** — 行の1文字が別のひらがなになります。Spaceで正しい行と変更箇所を表示します。
5. **ひらがな列車** — 文字を載せた列車が右から左へ走ります。Spaceで次の行に切り替えます。

対象は「あいうえお」〜「わをん」の10行・46文字（濁音・半濁音・小書き文字なし）です。

名前は日本語入力（IME）で確定するか、貼り付けて入力できます。
IMEの変換確定後、必要に応じてもう一度Enterを押してください。
ひらがな以外も使えます。結合濁点や絵文字も、見た目の1文字単位で扱います。
連打や長い貼り付け対策として、名前は最大32文字・512バイトです。
制御文字は取り除き、遊び中の無関係なキーは無視します。

文字表示は、大きな余白と二重枠を使う「ふつう」が初期設定です。
メニューで `d` を押すと、五十音46文字を36×14セルで描く「ドット」に切り替わります。
ドット表示に未対応の文字や44列×23行未満の端末では「ふつう」を使用します。
フォントサイズ自体は変更しないため、さらに大きく見せたい場合はターミナルの文字サイズを上げてください。
文字色は約0.8秒ごとに変わり、背景の点滅はありません。音は鳴りません。
表示する絵文字の形や幅はターミナルのフォントにより多少異なります。
終了すると元のターミナル画面に戻ります。名前の保存や外部送信はしません。
